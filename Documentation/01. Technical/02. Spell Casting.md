## Spell and HandConfig

### HandConfig Struct
`HandConfig` is a serializable data structure representing configuration details for a hand's spellcasting setup. It defines the properties required to customize a spell's visual, positional, and functional aspects for the player's hands.

#### Fields:
- `ElementType`: Specifies the elemental type (e.g., Fire, Water, Wind, etc.) of the spell.
- `CastTypes`: Defines how the spell is cast (e.g., Projectile, Stream, Touch).
- `_position`: Position offset for the spell's origin relative to the hand (Only available for touch spells).
- `_handEffect`: Visual effect attached to the hand during spell usage.
- `_spellPrefab`: Prefab for the spell object created when the spell is cast.
- `_handMaterial`: Material applied to the hand during spell casting.
- `_handColor`: Color overlay for the hand effect or material.
- `_poolSize`: Number of instances preloaded for the spell object (useful for object pooling).
- `_chargeEffect`: Effect displayed while the spell is charging (Only available for charge spells).
- `_audioClip`: Sound effect played during spell interaction.

### Spell Class
The `Spell` class is a ScriptableObject that encapsulates all data required for defining a spell in the game. This class enables spells to be created and managed in the Unity Editor without needing to modify code.

#### Fields:
- `_name`: The name of the spell.
- `_gestureSequence`: A sequence of gestures required to cast the spell.
- `_duoSpell`: Indicates whether the spell has 2 different spells (e.g. fire and water).
- `_primaryConfig`: Configuration for the primary hand when casting the spell.
- `_secondaryConfig`: Configuration for the secondary hand if the spell is a duo spell.
- `_isUnlocked`: Specifies whether the spell is available for use by the player.

### Usage:
#### HandConfig:
Used to define and customize how a spell behaves visually and functionally for a specific hand. Each spell has one or two `HandConfig` objects depending on whether it is a single or duo spell.

#### Spell:
- **Editor Setup**:
  - Create a new `Spell` object through the Unity Editor using the `CreateAssetMenu` functionality.
  - Populate the spell's fields with its name, gestures, and configuration details.

## SpellManager
The `SpellManager` class handles the management of spells in the game. It validates gestures against available spells, manages unlocking and locking of spells, and triggers associated visual and audio effects.

### Methods:
- `Awake()`: Registers the `SpellManager` as a service and initializes a cancellation token source for async operations.
- `OnEnable()`: Subscribes to gesture recognition and progression-related events.
- `OnDestroy()`: Unsubscribes from events and disposes of the cancellation token source.
- `HandleProgressionEvent(ProgressionData data)`: Unlocks or locks spells based on progression data received from the `ProgressionManager`.
- `IsSpellUnlockedForGesture(Gesture gesture)`: Checks if a spell associated with a given gesture is unlocked.
- `CheckSequence(List<Gesture> performedGestures)`: Validates the sequence of performed gestures against available spells. Updates the current spell if a match is found.
- `GetExactMatchingSpell(List<Gesture> performedGestures)`: Returns a spell that exactly matches the performed gesture sequence.
- `HasPartialMatchingSpell(List<Gesture> performedGestures)`: Checks if any spell partially matches the performed gesture sequence.
- `SetSpell(Spell spell)`: Sets the current spell, triggers visual and audio effects, and stores the spell as the last used.
- `HandleReset()`: Resets the current spell and resets hand visual effects.
- `HandleOnQuickCast()`: Quickly re-casts the last used spell, playing its visual and audio effects.
- `UnlockSpell(Spell spell)`: Marks a spell as unlocked, allowing it to be used in the game.
- `LockSpell(Spell spell)`: Marks a spell as locked, preventing it from being used.

## Cast
The `Cast` class handles the casting of spells from both hands and manages spell projectiles, charging, and effects. It supports various casting modes such as single fire, automatic, and charged. This class interacts with the `SpellManager`, `HandVfxManager`, and `ObjectPooler` for spell functionality.

### Methods
- `Awake()`: Subscribes to spell validation events and initializes the cancellation token source.
- `OnDestroy()`: Unsubscribes from spell validation events and disposes of the cancellation token source.
- `CastRightSpell()`: Initiates the casting process for the right hand.
- `CastLeftSpell()`: Initiates the casting process for the left hand.
- `StopRightCast()`: Stops the casting process for the right hand (only used for stream type spells).
- `StopLeftCast()`: Stops the casting process for the left hand (only used for stream type spells).
- `CastSpell(HandData handData)`: Handles the spell-casting process based on the hand data and cast type. Supports charged casting with visual and audio effects.
- `ExecuteSpell(HandData handData, CastTypes castType)`: Executes the spell based on the specified cast type (e.g., single fire, charged, automatic).
- `SingleCast(HandData handData)`: Executes a single instance of the spell and resets the hand's visual effects.
- `RepeatedCast(HandData handData)`: Continuously casts spells in rapid succession while the hand remains active.
- `GetSpellProjectile(HandData handData)`: Retrieves or spawns a spell projectile from the object pool, setting its position and parent.
- `StopCast(HandData handData)`: Stops an ongoing spell cast, resets visual effects, and disables the hand for further casting.
- `HandleSpellValidation()`: Enables both hands for casting after a spell is validated.
- `CastNoHands(Transform transform, string objectType, GameObject spellPrefab)`: Casts a spell without using hands, spawning the projectile at a specified location (used for testing).

## ElementType Enum
The `ElementType` enum defines the various elemental types associated with spells and abilities in the system.

### Values:
- `Fire`: Represents the fire element.
- `Water`: Represents the water element.
- `Earth`: Represents the earth element.
- `Air`: Represents the air element.

## CastTypes Enum
The `CastTypes` enum specifies the various casting methods available for spells. It determines how a spell is activated or executed by the user.

### Values:
- `SingleFire`: A single instance of the spell is cast when triggered.
- `Automatic`: The spell is repeatedly cast at regular intervals while the cast is active.
- `Charged`: The spell requires charging before being cast.
- `Touch`: The spell is cast upon direct contact or interaction with a target.
