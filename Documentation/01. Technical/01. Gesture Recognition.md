# Gesture Recognition
To check for Gestures the Unity XR Hands package is used. The limitation of this package is that only one handed gestures are recognised, the gestures needed to cast spells 
are made with 2 hands. To solve this issue a gesture system needed to be created That can recognise 2 handed gestures. For this reson the [Gesture script](../../Assets/Scripts/Gestures/Gesture.cs) was created.
